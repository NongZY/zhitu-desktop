# 自主学习流程修复记录

日期：2026-09-12。适用于本地 Docker 学习系统；未上传 GitHub。

## 原因与修复

- 已解析正文的教材因缺少手动知识点而无法确认：取消此前置要求；新解析成功后直接可学习，界面兼容旧的 review 状态，不再要求点击确认。
- PDF 正文导入不等于已有题目：保留已有题库优先，在学习者开始练习时为支持的数学章节补充基础填空题。题目明确标注为系统模板题，并非教材原题，也不是大模型生成。
- 按章练习包含所选章节的子章节，保留章节导航和按章节问答。
- 加载或网络错误被误报为没有教材：区分加载、空列表和失败，提供重新加载按钮。
- 章节请求失败时可能变成整本练习：失败时禁止开始，重试成功后恢复原章节选择。
- 补题未成功却显示未保存的题数：失败时回滚全部新增数据，并报告实际已保存题数。
- 简化导航与提示语；移除登录页演示账号入口，不删除任何用户账号。

## 使用方式与边界

打开“我的课本”，选择章节，点击“练一练”，选择 5/10/15 道题后开始。

基础补题目前覆盖绝对值、相反数、正负数、四则运算、乘方、一元一次方程、整式及余角等部分数学内容，依据章节标题匹配。题库不足且章节不受支持时会明确提示，不会假装已提取教材习题。

扫描件 OCR、任意学科的自动出题、公式和图形精确还原仍未完成。本次没有把模板练习当成完整 AI 题库能力。
