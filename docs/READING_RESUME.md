# 阅读位置保存与首页继续阅读

交付范围：学习者基础版 A 批。核验日期：2026-10-19。

## 已实现

- 按账户、教材保存最后成功显示的 PDF 页，稳定约 1 秒后发送保存请求，确认后显示“已保存”。
- 首页展示最近有效阅读记录；空教材库、未阅读和接口失败都有入口与提示。
- 父页面统一处理显式页码、目录、已存页、默认页；搜索和翻页更新地址，目录点击清除旧页码。
- 图片解码失败和迟到请求不写入位置。保存失败可重试，多窗口旧版本写入返回冲突。
- 按 PDF 内容 SHA-256 判断版本，页数相同的不同文件也会失效；页数与版本使用最多 128 项缓存。
- 新增两张表及幂等升级；旧备份仅允许缺少这两张新表，原有表和字段校验保留。
