## 故障原因与修复

PDF 第 11 页起有文字提取产生的 NUL 字符。PostgreSQL 拒绝写入此字符，
随后异常处理未先执行事务回滚，又触发 PendingRollbackError。
任务已经停止，但数据库中仍残留 processing / 10%。

本次改动：

1. 将 NUL 替换为可见的未知字符标记 `�`，避免直接删除而拼接数字或公式。
2. 数据库异常先回滚并重新读取任务，再保存失败状态。
3. 文本提取完成后，在单个事务中替换 PDF 生成的片段；失败时保留旧片段，
   重跑不会重复生成，也不会删除人工补充内容。
4. 记录页数进度、完成说明和错误信息，并在个人教材库卡片显示。
5. 没有文字的 PDF 显示需要 OCR，不再以零片段作为成功结果。
