# 知途桌面基础 D1（0.2.0-dev）

这是可开发运行的 Windows 桌面基础版，不是已发布的安装包。原网页版保留在 `E:\项目\学习系统`，应用版源码、依赖、数据库和窗口服务独立。

## 开发运行

在 PyCharm 打开 `E:\项目\学习系统应用版`，解释器选 `backend\.venv\Scripts\python.exe`，右键运行根目录 `run_desktop.py`。不运行 `run_local.py`，不需要 Docker 或虚拟化。启动器不会自动安装依赖、运行 npm 或打开浏览器。

开发环境首次准备（只需开发者执行）：

```powershell
Set-Location 'E:\项目\学习系统应用版'
G:\python\python.exe -m venv backend\.venv
Set-Location backend
.venv\Scripts\python.exe -m pip install -e '.[dev,desktop,migration]'
Set-Location ..\frontend
npm ci
npm run build
Set-Location ..
backend\.venv\Scripts\python.exe run_desktop.py
```

当前已在本机 Python 3.13.9、pywebview 6.2.1、EdgeChromium/WebView2 实际打开窗口。首个发行目标为 Windows 10/11 x64，不代表已经在干净 Windows 或全部系统版本验收。缺少 WebView2、界面构建或开发依赖会给出中文提示，不回退 IE。普通使用者无开发环境安装和离线运行时分发在 D4 实现。

## 本地数据与边界

- 默认目录：`%LOCALAPPDATA%\ZhiTu\`。`learning.db`（包括运行时 WAL/SHM）、`workspace.json`、`uploads\` 是学习数据，不能只复制单个正在使用的数据库文件当作备份。
- 新装为空空间，无注册、登录、密码或角色选择。清单 UUID 绑定稳定的内部 owner ID，不硬编码为 1，不自动采用旧数据库第一位用户。清单损坏／旧库缺清单时停止，保留原记录。
- `instance.lock` 由操作系统持锁，`instance.json` 只有激活窗口所需 PID/HWND 等非秘密信息。第二次启动激活现有窗口，不再启动数据库或解析器。
- 每次启动只监听随机 `127.0.0.1` 端口。所有 HTTP 路径（含首页、健康检查、PDF 图像）都校验短期凭据、Host 和 Origin。凭据仅在宿主、匿名管道和服务内存，不进入 JS、URL、环境变量或磁盘。
- 前端只有非秘密空间信息，忽略旧 JWT，不跳登录。PDF 原页经受保护请求转为 Blob；外部封面和在线字体已移除。CSP 阻止远程资源；外部导航在原生层拦截，用户点击的 HTTP(S) 链接交系统浏览器。
- 桌面设置只取显式启动配置，不读取 `.env` 或外部数据库／MinIO／Redis／AI 环境配置。AI 默认禁用；当前问答仍是已有的本地词项检索，不是新向量 RAG 或新 AI 生成。
- 关闭先等待已显示页的保存；冲突／失败不能宣称保存成功。未交卷练习提示留在软件或明确放弃，D1 没有作答草稿恢复。保存操作有超时限制，阅读确认框的时间不受这个限制；确认框存续时每秒发送一次非最终回应，连续 8 秒没有回应才触发原生退出确认。失效请求会撤销对应确认框，迟到选择不会关闭下一次会话。服务优雅退出上限 5 秒，超时仅终止自己的受控子进程，Windows Job Object 在宿主异常结束时清理服务。

这不是对同一 Windows 账户内恶意软件的防护，也不意味着 SQLite 已加密。不要把桌面服务作为免密码公网服务器部署。

本批实施取舍及代价：

| 决定 | 理由与代价 |
