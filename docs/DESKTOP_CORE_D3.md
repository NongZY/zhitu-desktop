# 知途 0.2.0-test.3：AI、教材补题和备份

交付日期：2026-10-29。此版本是独立 Windows 桌面测试版；网页版与真实学习数据未用于本批测试。

## 安装和试用

1. 关闭已运行的知途，双击 `E:\项目\学习系统应用版\dist\installers\ZhiTu-0.2.0-test.3-Setup.exe`。
2. 安装后打开桌面“知途（测试版）”。无需登录、Docker、Python、Node 或 PyCharm。
3. “我的课本”导入 PDF、DOCX、PPTX、TXT 或 MD，整理完成后进入“教材补题”。选择范围，查看正文片段，生成候选，核对并勾选保存，然后“去做练习”。
4. 需要 AI 时，在“设置”填入兼容 Chat Completions 的接口地址、模型和自己的密钥，分别开启问答/补题。问答还需在“问一问”勾选 AI；不开启时查找本地原文。
5. “设置 → 创建并导出备份”选择 ZIP 保存位置。恢复时选择备份，检查教材/题目/记录数量，确认后关闭并重开软件。旧空间保留，可安排返回；两个空间不自动合并。

也可运行完整目录包 `dist\ZhiTu-0.2.0-test.3\知途.exe`，不要只复制一个 EXE。需要系统已有 WebView2 和 .NET Framework 4.6.2+。本次不自动安装更新，原桌面快捷方式需完成安装后才指向新版。

## 本批新增行为

- AI 默认关闭，问答/补题分开授权；密钥使用当前 Windows 用户的 DPAPI 保护，不在读取接口、错误提示、日志或备份中显示。改设置后取消在途调用并丢弃迟到结果，不自动重试付费请求。
- 补题根据所选教材实际正文，提供单选、多选、判断、填空、简答候选。支持来源定位、编辑、确认保存、停止和手动重试；重复结果不虚报完成。填空每空一行并按顺序判分，简答自行核对。
- 新建练习保存题目快照，后改题目不改写原来的答案与评分依据。旧记录没有快照时明确提示无法保证原题版本；已被练习使用的题目/教材暂不允许直接删除。
- 完整备份包含一致性数据库快照、教材原件、题库、阅读和答题记录。校验清单哈希、数据库关系及原件导入时的摘要和大小；恢复先放入独立空间，下次启动再切换，失败保留当前空间。

## 当前限制

- 本地规则只覆盖正文中明确出现的部分数学知识，不承诺所有学科自动出题。“课本原题”仅识别明确标注题目和答案的有限文本格式，不猜缺失答案。AI 候选也需要核对。
- 每章最多使用 12 段、6000 字正文，每批最多 100 个章节范围/500 道目标题。页面展示实际选用片段，不能视为读完了整本教材。
- 未进行真实服务商付费调用；不同接口/模型兼容性需使用自己的配置测试。兼容接口当前使用 Chat Completions。
- 扫描件可看原页，未加入 OCR 或本地模型；复杂 Office 排版/公式不保证还原，MD 关联图片未导入。PDF 原页阅读保留公式、插图与底色。
- 仅支持本软件单人桌面空间备份，ZIP 最大 2 GB、解压总量最大 4 GB；AI 设置和密钥不随备份迁移。`pre-upgrade` 目录是升级前数据库/空间信息副本，原件仍在原处，不是可导入 ZIP。
- 实际数据在 `%LOCALAPPDATA%\ZhiTu\`，不在安装目录。安装版/目录版共用此空间；本批未迁移原网页版数据，未执行干净电脑兼容验收，也未将新功能同步到网页版。
- D2 已记录的小问题仍保留：首次只打开较短资料可能尚未生成继续阅读记录、部分中断导入提示措辞、安装器检测 WebView2 残留版本的边界。详见 [D2 记录](DESKTOP_DOCUMENTS_D2.md)。
