## 使用入口

1. 学习总览 → 最近练习或巩固建议 → 查看详情。
2. 学习进度 → 知识地图节点或知识点列表 → 回到课本 / 练习这个知识点。
3. 学习记录 → 查看详情 → 逐题核对。
4. 做练习 → 勾选题型 → 开始练习。
