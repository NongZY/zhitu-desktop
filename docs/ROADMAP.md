# 分阶段实施路线图

本路线图把项目构建报告拆成可验证的交付门槛。每一阶段都必须先通过上一阶段的功能、安全与数据质量验收，再扩大 AI 自动化范围。

## 当前交付基线

当前仓库已经形成可运行的阶段一 MVP，并提供阶段二、三的关键接口：

- JWT 注册登录与学习者私有空间隔离；
- 个人教材库、树形章节、本地/全局知识点及映射关系；
- PDF 上传、Celery 解析任务、PyMuPDF 文本分块与任务进度；
- 个人题库录入、筛选、确认状态和批量导入 API；
- 随机/自适应组卷、全屏倒计时、客观题评分、成绩与错题本；
- 基于全局知识点的掌握度更新、薄弱点权重与学习路径；
- 可拒答、带教材/章节/页码引用的关键词检索问答，并预留 OpenAI-compatible LLM；
- Vue 3 学习端、FastAPI OpenAPI、PostgreSQL/Redis/MinIO/Docker Compose。

当前 RAG 使用数据库片段的轻量关键词检索，目的是让无模型、无 API Key 环境也可运行。向量模型、OCR 和自动知识抽取属于后续增强，不能把接口占位误认为已达到生产质量。

## 阶段一：MVP 闭环

目标：验证“自主导入教材—建题—练习—反馈”是否为学习者创造真实价值。

### 范围

- 学习者注册、登录和私有数据隔离；
- 学习者自行导入教材、校对章节和知识点；
- 个人题库录入、筛选和批量导入；
- 随机组卷、考试作答、自动评分；
- 成绩记录、错题本、基础掌握度；
- Web 端与一键 Docker 部署。

### 验收门槛

- 新学习者能完整走通注册、导入教材、校对内容、组卷、作答和查看结果；
- 未经学习者确认的题目不进入可用题库，测试中接口不泄露答案；
- 同一试卷重复交卷被服务端拒绝；
- 后端测试、前端类型检查/测试/生产构建、Compose 配置全部通过；
- 每份教材、题目和答题数据都绑定所有者，其他学习者无法访问，并有明确备份说明。

## 阶段二：教材解析与 RAG

目标：降低教材结构化成本，并让问答的每个结论可追溯。

### 建设项

- 抽样检测数字 PDF 与扫描 PDF，按页进入 PyMuPDF 或 PaddleOCR；
- 版面分析、目录/章节识别、页眉页脚清理、坐标与页码保留；
- 章节、知识点、习题与答案生成候选，并进入学习者校对确认界面；
- BGE 中文嵌入、向量索引、关键词混合检索与重排；
- 教材权限过滤、证据阈值、拒答和引用一致性验证；
- LLM 生成题保存模型、提示词、来源与学习者确认记录。

### 验收门槛

- 建立至少三类真实教材的标注集，分别评测目录、正文、习题和答案提取；
- RAG 固定问题集达到约定的 Recall@K、引用命中率、忠实度和拒答准确率；
- 重新解析生成新草稿版本，不覆盖学习者已经确认的修改；
- OCR/嵌入/LLM 故障时，MVP 非 AI 功能继续可用；
- 私有教材不能被其他学习者检索或整本重构下载。

## 阶段三：自适应与成长性学习

目标：用可解释、可回放的数据模型驱动下一步学习。

### 建设项

- 掌握度加入时间衰减、作答时长异常、题目难度与证据质量；
- 组卷加入题型/难度配额、重复间隔、前置知识复习和多样性约束；
- 本地知识点到全局知识点的自动映射候选与学习者确认；
- 全局前置/包含关系治理、跨教材错题与掌握度延续；
- 学习者可查看“为何推荐这道题”和掌握度更新证据；
- 雷达图、知识图谱、阶段报告和学习路径推荐。

### 验收门槛

- 每次掌握度变化可追溯到答题证据与算法版本，并可离线回放；
- 冷启动、少量错误和长期未练不会导致极端推荐；
- A/B 或准实验显示个性化策略相对随机策略有稳定收益；
- 按难度、题型和不同历史数据量完成偏差与稳定性检查；
- 映射未确认时不污染学习者自己的跨教材学习画像；
- 跨教材掌握度、错题和路径推荐只在同一学习者的私有数据内延续，不跨账户聚合或迁移。

## 阶段四：生产化与扩展

目标：让面向个人的自主学习服务具备稳定、安全、可持续运行能力。

- PostgreSQL 迁移、索引、读写容量规划与恢复演练；
- Prometheus/Grafana、结构化日志、任务死信与告警；
- 限流、审计、恶意文件扫描、密钥轮换、隐私导出/删除；
- 多设备同步、PWA/移动端适配、离线缓存与弱网恢复；
- 个人存储配额、模型调用预算、数据归档和账户注销流程；
- 当容量数据证明需要时，将文档处理/RAG worker 独立扩缩容，并评估 Milvus；
- 教材权利提示、题目许可清单、未成年人数据保护和正式合规评审。

## 不应提前跨越的边界

- 没有学习者确认与评测集时，不自动启用 LLM 题目或知识映射；
- 没有版权依据时，不公开传播教材正文或批量导入网络题；
- 没有足够历史数据时，不宣称掌握度是精确的心理测量结果；
- 没有明确容量或团队边界时，不把模块化单体拆成大量微服务；
- 没有对象级权限过滤时，不把私有教材片段发送给外部模型。
