# 原页阅读与公式显示更新

更新部署：2026-09-28；公式边界保护补丁及最终核验：2026-09-29。

## 本次解决的问题

教材中的自定义字体、公式上下标和分数布局不能可靠地还原为普通文字。把提取文字直接作为阅读正文，会丢失插图、颜色和公式结构。本次将“看原书”和“用文字找内容”分开，并让题目等应用内容复用统一公式显示模块。

## 已部署功能

- 课本详情默认显示原 PDF 页面，不再默认用提取文字代替原书。公式、彩色框、插图及原书底色保留。
- 点击目录章节跳到对应 PDF 页；支持上一页、下一页、页码跳转和缩放。
- 支持整本书或当前章节关键词查找，结果按页去重、分页，点击结果定位原页。
- 提取文字改为可选展开的辅助内容；搜索摘要明确标注仅用于找页。
- 阅读器外部可切换护眼背景，不对 PDF 图片加变色滤镜。
- 练习题干、选项、答题报告、参考答案、解析、错题和问答正文使用同一公式显示模块。
- 支持明确的 LaTeX 公式及常见键盘记法：`(-1)^4` 显示为四次方，`*` 显示乘法，`sqrt(9)` 显示根号，明确的除法显示分数。`^` 不作为乘号或根号解释。
- 对无法可靠识别或有歧义的表达式保留原文，不猜测补全。KaTeX 禁止可信 HTML、链接及图片命令；普通文字保持转义。
- 补充保护空格分隔的数字和不明确的根号范围：`1 1/2` 不会误拼成 `11/2`，`√x^2` 保留原文；明确写成 `√(x^2)` 或 `√(x)^2` 时才分别排版。
- 检索到标记为公式待核对的片段时，问答不会把不可靠内容交给大模型推算，而是提供原文出处供核对。

## 使用方法

1. 打开 <http://localhost:8080/>，已有页面可按 Ctrl+F5 刷新。
2. 登录后打开自己的数学课本，在左侧目录点击章节。
3. 在阅读器中输入“正数和负数”或“绝对值”查找，点击结果跳到原页。
4. 如需复制文字，可展开辅助提取文字；涉及公式时以原页为准。

## 当前边界

- 本次搜索定位到“页”，尚未实现原页中逐字或逐公式精确高亮。
- 搜索依赖已有的提取文字，不保证找到未识别的扫描图片文字、复杂公式或跨分块关键词。
- PDF 页码包括封面，可能不同于纸面印刷页码。
- 显示修复不等于所有历史提取文字都已纠正。本次保留旧数据，不自动重解析整本教材。
- 公式渲染不负责计算答案，也不改变评分规则；复杂、歧义或损坏的输入会回退为原文。
- 不包含公式输入键盘、通用数学 OCR 或所有公式的自动纠错。

公式补丁回归：新增测试先复现 8 个失败断言，确认错误在键盘记法转换阶段已出现，而不是 KaTeX 排版或 PDF 图片导致。原因是隐式乘法拼接了相邻数字，且裸根号没有保留范围不明的信息。增加歧义检查后，同一组测试和全部前端测试通过；正常的 `2x`、`2(x+1)`、`(-1)^4`、分数及明确根号写法不受影响。
