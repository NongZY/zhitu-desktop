# 知途 Windows 本地学习软件设计

日期：2026-10-20。目标版本：`0.2.0`。

状态：用户已在 2026-10-20 指示按当前方案构建独立应用版，Windows 桌面、独立保留网页版、免登录、核心本地化、多格式资料及教材内容补题按本稿与共同设计推进。已进入[首批 D1 实施计划](../plans/2026-10-20-desktop-foundation-d1.md)的审阅阶段，尚未进入产品代码实现；目标版本号不代表已经发布。

2026-10-20 补充并澄清：两端根据导入教材的正文、例题和知识要点补充配套题，即使原书没有习题也能生成候选，详见[教材内容驱动的补题设计](2026-10-20-textbook-question-fill-design.md)。不新增脱离教材的通用题库或自由主题出题；本稿相应扩展 AI 设置与教材题库范围，仍不代表功能已经实现。

## 1. 目的与成功标准

面向不同年龄的自主学习者，把现有网页版转为安装后双击使用的 Windows 软件。学习者添加自己的资料，阅读、搜索、练习并保存学习记录；不需要注册、登录、选择身份、启动 Docker 或操作命令行。

默认单人本地学习空间。核心功能断网可用，用户主动开启 AI 后，才允许把问题和少量相关片段发送到自己配置的接口。自动出题、OCR 和语义理解的能力必须如实展示，不以桌面打包代替尚未完成的功能。

原网页版完整保留在 `E:\项目\学习系统`，基线是 `web-2026.10.20`／`bb7963256f3c79dff996013b6dde7976b63ea3ae`。新项目放在 `E:\项目\学习系统应用版`，独立 Git 仓库与开发分支，不共享真实运行数据。具体来源见 [版本来源记录](../../VERSION_LINEAGE.md)。

## 2. 方案选择与发布边界

| 路线 | 对现有代码的影响 | 本次决定 |
| --- | --- | --- |
| pywebview＋Vue＋Python 服务 | 复用当前界面、解析和学习逻辑，需要补齐进程管理与打包 | 采用 |
| Tauri＋Python sidecar | 同样可复用业务，但增加 Rust 构建与跨进程配置 | 作为后续替代方案，不同时建设 |
| Electron＋Python 服务 | 可复用 Web 界面，但增加 Electron 与 Python 双运行时维护 | 本次不采用 |

首个正式发布面向 Windows 10/11 x64，以实测环境说明兼容范围；不承诺 Windows 7、ARM、macOS、Linux 或手机端。开发和打包环境可以安装构建工具，但普通使用者不需要 Python、Node.js、PyCharm、PostgreSQL、Redis、MinIO、Docker 或虚拟化支持。

pywebview 固定使用 EdgeChromium/WebView2，不回退到旧 IE 内核。先产出可独立运行的目录包供验收，再用安装器分发。正式安装器须检测 WebView2 等运行时；离线发行包含所需的离线安装来源，不在首次运行时偷偷下载依赖。不能预先承诺体积、启动速度或所有电脑兼容性。

## 3. 当前基线与必须改变的地方

本节来自源码核对，而不是新应用版验收：

- `run_local.py` 已能以 SQLite、本地文件和本地导入线程运行，但仍依赖开发环境，可能调用 npm，默认打开浏览器且需要登录。
- 前后端多处依赖当前用户 ID；教材、阅读位置、错题、掌握度等保留所有权和外键关系。仅删除登录页面会使这些流程失效。
- 导入接口、解析任务、阅读器与进度接口目前只处理 PDF。扫描页没有 OCR；特殊字体修复只覆盖已有特定教材，不能当作通用公式识别。
- 问答是本地词项重叠检索，最多读取前 1000 个片段；不是向量检索。云端接口配置来自环境，失败降级信息不充分。
- 题型支持单选、多选、填空、判断、简答；基础补题只覆盖有限数学模板。简答题没有可靠自动评分。
- 前端包含在线字体请求，桌面离线版需要移除；现有 MinIO 和 AI 环境配置不能被桌面模式无条件继承。
- 阅读续读已实现；先前学习者改版设计中的问答联动、草稿恢复、精确重做等其他批次不能视为全部已完成。

本稿的桌面宿主、免登录和数据目录约定只对独立应用版生效，覆盖旧设计中“暂不应用化”和“所有流程必须账户登录”的相关限制。新增的题库与出题行为按两端共同设计适用于网页版和应用版，但不修改原网页版的登录及所有权边界。

## 4. 模块与启动生命周期

| 模块 | 负责 | 不负责 |
| --- | --- | --- |
| 桌面宿主 | 单实例、窗口、原生文件选择、启动握手、关闭与故障提示 | 学习算法与解析细节 |
| 本地运行上下文 | 专用配置、数据目录、学习空间、每次启动访问凭据 | 复用旧环境中的云端凭证 |
| 学习业务 | 教材、题库、考试、错题、统计和进度 | 直接操纵桌面窗口 |
| 资料处理 | 格式校验、解析、规范化阅读产物、目录及来源定位 | 将未知公式猜成确定文本 |
| AI 连接与问答服务 | 本地检索、共用的可选模型连接、引用与降级状态 | 未获开启就联网、把问答请求隐式变成收费出题 |
| 教材配套出题服务 | 按教材正文与章节要点匹配已有题、规则变式或 API 生成候选，确认后保存 | 脱离教材的自由主题出题、不核对就把 AI 答案视为标准 |
| 数据维护 | 一致备份、显式迁移、校验与恢复 | 自动覆盖原网页版数据 |

桌面主线程管理窗口，受控后台服务运行 FastAPI。仅监听 `127.0.0.1`，由系统分配可用端口，不固定占用网页版 8081。窗口在服务就绪后加载随包提供的 Vue 静态文件，不启动开发服务器，也不在使用者电脑上构建前端。

单实例锁按 Windows 用户的数据目录区分。重复双击激活现有窗口，不同时升级或写入同一数据库。关闭时先提示未完成导入，提供继续等待或取消并退出；后台解析须可协作取消或受控终止，不能无限等当前线程。保存失败不能显示“已保存”；强退后重新启动显示中断任务和重试入口，不留下孤儿服务。

桌面专用配置不读取当前工作目录 `.env`，不继承外部数据库、对象存储、Redis 或 AI 配置。旧 Web 依赖应按实际加载边界拆成可选部分，而不是只从依赖列表删除后留下 import 错误。

## 5. 免登录与本地数据边界

首次启动自动建立一个本地学习空间，内部保留稳定的所有者标识，继续通过统一访问层校验资源。新界面不出现邮箱、密码、身份等级或退出登录；前端用本地启动上下文替代 token 登录状态、过期重定向和 `auth.user` 依赖，阅读保存不能因用户 ID 为空而停用。

不硬编码 `user_id=1`，不自动选择旧数据库第一名用户。兼容阶段保留现有 User 表与相关外键，内部身份不提供公开登录能力。桌面注册／登录接口停用；不能通过“任意请求自动登录”的逻辑影响旧服务器部署。

本地服务仍需要每次启动随机访问凭据、Host/Origin 校验和资源归属检查。凭据只交给当前窗口，不放 URL、持久化浏览器存储或日志；CORS 不是身份验证的替代。静态页面、教材资源与设置写入入口都处于明确边界内，不能让外部网页读取本地教材或修改 API 配置。此边界不宣称抵御已控制同一 Windows 用户的恶意程序。

应用只加载自带的界面；外部链接需用户点击后交系统浏览器打开，不在带本地权限的窗口加载远程页面。文档、Markdown、模型输出均按不可信内容处理，禁脚本与事件属性。

运行数据默认位于 `%LOCALAPPDATA%\ZhiTu\`：数据库、托管原件、解析产物、缓存、日志、备份分别管理。不得写在安装目录、源码目录或临时解包目录。设置提供打开数据目录、备份和恢复入口；第一版不做任意数据目录搬迁或多设备同步。

API 密钥使用 Windows Credential Manager／系统保护机制保存，非秘密配置单独持久化。前端只接收“已配置”状态及掩码；日志和默认备份不含明文密钥。普通本地数据库不是天然加密数据库，共用 Windows 账户的人可能访问文件；界面应说明依赖操作系统账户保护，不能宣传为密码保险箱。

## 6. 多格式学习资料

用户要求资料不局限 PDF。首个正式应用版的拟支持范围如下，具体能力按格式逐项验收，不只是修改上传后缀白名单：

| 格式 | 目录／内容 | 阅读与定位 | 明确限制 |
| --- | --- | --- | --- |
| PDF | 书签／正文规则、可提取文字 | 原页图像、PDF 物理页 | 扫描件可读，但没有 OCR 时不能声称全文可搜 |
| DOCX | 标题、正文、列表、常见表格与嵌入图片 | 结构化阅读、标题／块定位 | 不伪造 Word 页码；复杂排版、公式和嵌入对象可能需原文件核对 |
| PPTX | 幻灯片标题、文本、常见表格与图片 | 按幻灯片分组的结构化阅读，定位到幻灯片／块 | 不是完整 PowerPoint 渲染器；动画、SmartArt 和复杂对象不承诺还原 |
| TXT | 文本、行段；无可靠标题时显示“全文” | 段落／行定位 | 不强行生成章节或学习概念 |
| Markdown（MD） | 标题、正文、列表、表格、代码与本地关联图片 | 安全渲染，标题／块定位 | 禁执行 HTML／脚本，不自动访问远程图片或越界路径 |

DOCX/PPTX 在未安装 Office 的电脑上也须能完成上述结构化阅读和内容查找。仅提供“调用系统打开原文件”不算该格式已经支持；该入口只能作为用户主动选择的补充。DOCX 可采用 python-docx、PPTX 可采用 python-pptx，解析层不能把这些库误当成原样页面渲染引擎。

旧 DOC/PPT、EPUB、Excel、音视频、网页采集和宏文档不在首批支持范围；明确说明替代方法，不静默交给 PDF 解析器。可选的本地 LibreOffice 转 PDF 是后续独立组件，需要单独验收映射、字体和公式，不作为第一版结构化阅读的隐式依赖。

TXT/MD 优先严格识别 UTF-8/BOM，兼容明确支持的中文编码；不确定时提供编码选择和预览，不用替换字符把乱码当成功。公式中的 `^` 在明确数学语法中表示幂，不能全局替换成乘号或根号。无法可靠提取的公式和对象显示位置与核对提示，不直接送模型补猜。

## 7. 来源版本、目录和定位契约

保留现有 `Textbook` 作为一份学习资料的业务标识，避免为改名重建全部题库关系；界面可用“学习资料／我的教材”。多格式能力在独立文档服务中实现，不在前端散落按后缀猜测逻辑。

新增不可变来源记录，至少包含 `source_id, textbook_id, format, original_name, managed_file, byte_size, source_revision`。`source_revision` 为原始字节 SHA-256。路径是服务端内部信息，不接受客户端随意传入路径读取。教材当前来源与某次导入任务绑定的来源必须分开，避免连续上传时旧任务解析新文件。

规范化阅读产物包含有顺序的标题、段落、表格、图片与未知对象块；产物版本 `rendition_revision` 由来源、解析器版本与规范化结果确定。非分页块标识不能在重新解析后无提示地指向另一个段落。

目录、片段、搜索结果、引用和阅读进度共同使用定位信息：`source_id, source_revision, rendition_revision, kind(page|slide|block), unit_id, offset?`。PDF 页和幻灯片序号从 1 开始；块定位不叫页码。章节 ID 是辅助信息，不替代来源定位。

旧 PDF 的 `page_number`、`document_revision` 和页面 URL 保留适配，原页码按原文件摘要迁移，不清空旧续读。旧字段只对 PDF 使用，其他格式不能硬塞虚构页码。进度继续使用乐观版本控制，阅读目标成功显示后才保存。

同一来源的旧阅读产物在切换解析器后继续可访问，旧引用和续读不能因块重新编号而静默漂移。更换源文件后提示重新选择位置；自动猜测的映射不得直接覆盖原位置。缺失原件时标记不可验证，不生成虚假摘要。实现采用有版本、可重复执行的增量迁移，不把 `create_all` 当成已有表结构升级机制。

## 8. 本地导入、搜索与原文核对

流程为“选择资料 → 校验并复制托管原件 → 创建绑定来源的任务 → 解析阅读内容与目录 → 建立索引 → 发布新版本”。读写任务状态在本机持久化。复制成功后，即使用户移动原文件也不影响软件内资料。

解析在后台执行，显示实际阶段与已处理页／幻灯片／块，不伪造恒定进度。文字 PDF 可提前打开原页，扫描 PDF 即使不能提取文字也可进入阅读，状态区分“可阅读”和“可搜索”。Office 文件只有规范化阅读产物准备好后才显示可阅读，不能用空白界面表示成功。

失败、中断、磁盘满和不支持内容均保留可解释状态。提供使用已保存原件重试，不要求重新上传；第一版是完整重试，不承诺解析到一半的断点续跑。任务重试幂等，不重复创建教材。相同文件重复添加时提供打开已有资料或明确另建副本的选择，不擅自合并学习记录。

解析产物先暂存，成功后事务发布；失败不替换已有可读内容，不删除手工知识点／题目。重解析需保持来源与产物关系，避免把不同格式的片段混在一起。

初期建立覆盖整份资料的本地全文／词项检索，配合中文召回测试，修复前 1000 片段截断；不引入外部向量服务，不宣传为已经具备语义向量检索。点击搜索或问答来源打开经过校验的页、幻灯片或块，不能从模型文字中解析一个页码当作来源。

校验后缀、真实结构、大小、解压总量、成员数量和处理资源上限，拒绝不支持的加密或宏文件。OOXML 禁止路径穿越、外部实体、外部关系抓取和嵌入对象执行。Markdown 图片只读取明确导入的关联文件，不遍历任意本地文件；远程资源默认阻止。日志只记录错误类型、阶段和匿名标识，不写教材正文。

## 9. AI 设置、调用与失败降级

设置包含启用开关、兼容协议说明、Base URL、模型名称、密钥保存／清除和连接测试。第一版只支持 OpenAI 兼容 Chat Completions 接口；并非任意提供商都兼容，不支持的协议不能假报连接成功。HTTPS 为远程默认要求，本机模型服务可使用明确的回环地址。

默认关闭且不从旧 `.env` 自动启用。连接测试使用无教材的最小模型请求，提示可能产生少量费用。配置保存后运行时生效；更换或关闭配置影响后续请求，关闭时尽力取消进行中的调用并说明已发送内容无法撤回。

正常问答发送当前问题和限定范围内的少量检索片段，不发送整本源文件、账户、答卷或全部学习记录。调用前可看到提供商／接口与涉及资料，第一次开启明确说明外发范围。默认关闭遥测、远程字体和远程文档图片；如系统 WebView2 自身有更新行为，不把它误称为应用教材上传。

返回状态区分“AI 根据资料讲解”“本地资料摘录”“暂未找到依据”；无配置、断网、401、限流、额度不足和超时分别给出简单提示。模型回答有引用不代表每一句都经过事实验证。公式待核对的片段不让模型猜测答案，仍能查看对应原文。

AI 连接配置同时服务问答和教材补题，两种用途分别启用；补题绑定已导入教材与章节，仅发送本次题型／题量等条件和相应正文片段，生成候选经预览、修改、确认后保存到该教材。原书无习题也可基于正文生成，但不能只依据书名／章节名或脱离教材自由出题；具体流程、状态、费用与失败契约按两端共同设计执行，不在导入或开始练习时静默调用付费接口。

长期对话记忆和跨设备聊天同步仍不纳入。后续若连接本地模型服务，仍使用同样的显式设置与来源边界，不强制捆绑大模型权重，也不宣称已经支持离线 AI 生成。

## 10. 既有学习功能与本次不扩大的范围

保留章节、知识点、题库、练习／考试、结果详情、错题、掌握度和阅读恢复。桌面身份与文件定位改变时，对这些现有入口做回归，不能为去登录而删除历史关联。

题型仍为单选、多选、填空、判断、简答；简答题明确未自动评分，不当成客观错题。现有数学模板明确标记为系统基础练习，不冒充教材原题；题量不足给出范围与原因，不偷偷放宽条件。新的非 PDF 资料不等于自动具备该学科的题库。

补题范围以当前教材正文为依据，原题整理、经验证的规则变式和可选 API 生成均服务于该教材的学习内容，按两端共同设计分批交付。不新增无教材题库，不解除教材归属；当前尚未实现的生成任务、历史快照和来源版本需要相应验收，不能只按章节名称匹配模板就宣称已理解教材。

本次仍不承诺完成旧方案未交付的作答会话／草稿恢复、间隔复习、不受范围限制的全学科可靠自动出题、知识图谱自动建设或主观题自动评分，不能通过改统计文字宣称已实现。

## 11. 旧数据迁移、备份与回退

新装默认空空间。设置可显式选择“导入旧版学习数据”；不自动寻找或打开网页版正在使用的数据库。用户已有的迁移需求继续保留，但真正迁移须以当时可读取、明确选定的源为准，不默认为旧日期备份仍是最新数据。

迁移流程：获得源库一致快照与配套原件 → 列出可选旧空间及缺失文件 → 用户选择一个 → 在新的暂存目录升级并复制 → 核验表记录、关联、原件摘要和进度 → 原子启用。首版保留内部 ID，避免隐式跨账户合并。未选中的账户在隔离副本内保留而不暴露切换入口，不删除原数据。

SQLite 使用备份 API 或停机一致复制，不能忽略 WAL。MinIO 等远程路径无法读取时先报告并要求补齐，不能悄悄丢书或开启外网迁移。失败不切换学习空间，重试不重复写入。不得从源登录密钥或密码推导桌面访问凭据。

备份为带版本、清单与文件摘要的数据库和托管原件组合，默认不含 API 密钥或临时日志。恢复到独立目录验证后再切换，不覆盖唯一可用副本。升级前保留备份；不兼容的旧程序拒绝误写较新数据库。卸载默认保留学习数据，删除数据必须由用户明确选择。

## 12. 分批交付与停止点

这是整体设计，不把所有子系统合成一次巨大的代码任务。每批有独立实施计划、测试和可交付证据：

| 批次 | 交付范围 | 停止点 |
| --- | --- | --- |
| D1 桌面基础 | 专用配置、数据目录、稳定本地身份、免登录前端、受控窗口与本地服务生命周期 | 先使用合成资料验证原有 PDF 学习闭环，不操作真实旧库 |
| D2 多格式资料 | 来源／产物／定位契约、PDF 兼容、TXT/MD、DOCX/PPTX、目录搜索与引用跳转、可重试任务 | 五类格式逐项验收；仅完成 PDF 或 TXT 不称正式应用版已完成 |
| D3 设置与数据维护 | AI 设置及密钥保护、明确降级、显式旧数据迁移和备份恢复 | 接口失败不阻断本地学习，迁移验证在副本上通过 |
| T1—T3 两端共同补题 | 教材正文依据与已有题覆盖、规则／API 配套题、候选确认保存、按章批量任务和适用格式的原题整理 | T2 依赖 T1、历史保护及本端设置边界；不按书名猜题，不局限原书已有习题 |
| D4 安装发布 | 依赖裁剪、静态资源、目录包、安装器、运行时检查及干净 Windows 验证 | 达到首个正式发布验收后才创建应用版发布标签 |

本稿批准后先制定 D1 实施计划，并让用户审阅计划、选择执行方式，再开始业务代码。后续批次延续相同边界，不在 D1 期间顺带实现大模型、OCR 或公开部署。

## 13. 必须通过的验收

- V1：原网页版基线分支和标签固定于 `bb79632`／`web-2026.10.20`；应用改造不写原网页版业务代码或真实数据库。网页版获授权的方案更新在独立规划分支进行，不移动已保留的基线。
- V2：没有 Python、Node、PyCharm 或 Docker 的支持范围内 Windows 电脑，按发行说明断网安装、双击进入，无注册登录；缺少 WebView2 有完整离线安装路径。
- V3：关闭 AI 时，添加／解析／阅读／检索／练习没有应用主动外发教材、字体或日志请求；旧环境变量不能启用 MinIO 或云模型。
- V4：普通 PDF 的插图、底色、幂和根号保持原页；扫描 PDF 可阅读且正确说明搜索边界；不能把坏文字当成已正确识别。
- V5：DOCX/PPTX 在未装 Office 的电脑上能结构化阅读、按标题／幻灯片查找；TXT/MD 编码、表格、关联图片及不可信脚本处理符合范围；复杂对象有核对提示。
- V6：每种支持格式的目录、搜索、引用和重启续读定位同一来源；超过 1000 片段的资料尾部能召回；无可靠依据时不输出确定答案。
- V7：替换文件和解析器版本变更不让旧引用静默漂移；旧 PDF 页码和已有进度兼容；迟到任务不能发布错误来源。
- V8：导入中断、取消、磁盘满、损坏或伪装文件均有明确结果；原件可复用重试，旧内容和人工学习数据不被半更新。
- V9：五种题型正常作答，判断 false 与未答区别正确；题量不足与简答未自动评分如实说明，不因新格式而承诺通用自动出题。
- V10：有效接口可回答；无密钥、错误密钥、限流、额度不足、断网和超时都可继续本地学习；实际请求不带整本文件或学习档案，密钥不出现在前端响应、日志或默认备份。
- V11：第二实例不争抢同库；关闭／强退后可重启，没有遗留服务占端口；其他网页不能直接读取教材或修改设置。
- V12：旧数据复制、选择、校验、失败重试、恢复和升级回退均在独立副本证明；默认卸载不删学习数据。
- V13：共同设计的 TV1—TV9 通过，特别是无习题教材也能按正文生成配套候选、来源可核对、不超出选择范围、已保存题断网可用和不静默付费补题；不以桌面原有测试替代共同新功能验收。

测试以合成且获许可的多格式资料为主，真实教材测试显式提供文件，不把教材或账户备份加入 Git。记录每项已运行证据，不用网页版旧测试结果代替桌面实测。
