# 网页版与应用版：根据导入教材内容补充练习题

日期：2026-10-20。适用：网页版与独立 Windows 应用版。

状态：用户已明确要求两端加入此功能，并纠正了“独立于教材的通用题库”方向。本稿只定义后续范围，尚未实现；书面设计和各批实施计划审阅后再执行，不操作真实数据库或模型接口。

## 1. 用户目标与范围

学习者导入一本教材，系统理解其中章节、正文和可确认的知识要点，为这些内容补充配套练习。原书有习题时可以整理；原书没有习题或题量不足时，也可依据正文生成相关的新题，而不是只摘抄原书习题。

采用“教材内容驱动的补题”，不采用“脱离教材按任意主题出题”或“独立通用题库先行”。不能只根据书名、学科、章节名或模型常识填题；每道新增配套题必须与所选教材正文中的概念、方法或例题有可核对的关联。不是要求题干和答案逐字来自原书，而是考查范围由教材实际内容约束。

本次不新增无教材题库、自由主题出题、通用基础题包下载、跨端题包交换或公共题库抓取。保留现有教材题库和手动录题功能，不删除旧题或学习记录。网页版保留账户登录和私有教材隔离，应用版使用本地学习空间，两端不自动同步数据。

## 2. 学习者操作与补题时机

流程：导入教材 → 整理可读正文与目录 → 选择整本书或某章 → 根据相关正文补题 → 预览／修改／确认 → 保存到该教材题库 → 练习与复习。

- 导入完成后显示“为这本教材补充练习”；章节页提供“补充本章练习”。默认提供少量练习建议和五类题型选择，高级难度与数量设置可展开，不要求学习者理解提示词或切分参数。
- 可查看当前范围已有多少可练题、哪些要点尚缺题。没有正式知识点结构时仍可按章节正文补题，不要求先校对整本知识图谱。
- 可以整本按章批量补充，但必须逐章使用实际内容，显示各章任务和实际题数，不用一次提示词声称读完全部教材。
- 导入和开始练习均不静默调用付费接口。用户可主动点击补题，或在本次导入中明确选择“整理后自动补题”，预先看到范围、目标题量、接口及可能费用；这一选择不能变成以后所有导入的隐式授权。
- 没有教材正文、解析仍在进行或公式不可可靠读取时，说明原因与下一步，不根据标题凭空出题，不误报已完成。

## 3. 如何补充与教材相关的题

| 方式 | 如何关联教材 | 使用边界 |
| --- | --- | --- |
| 已有教材题 | 优先使用当前学习者、当前教材与所选章节已确认的题目 | 不拿其他账户或无关教材题凑数量 |
| 原书习题整理 | 从所选教材识别原题、答案及来源位置，形成候选 | 属于补充来源，不是唯一来源；缺答案、乱码或版式不明时不猜测 |
| 可验证规则变式 | 根据正文中已经出现的概念／计算方法，匹配经验证的模板，生成新条件并确定性求解 | 目前只有有限数学模板；仅章节名称命中不够，不拓展到未介绍的概念 |
| API 生成配套题 | 以当前教材相关正文、例题或知识要点为依据，生成考查这些内容的新题与解析 | 默认关闭，显式调用；不超出证据支持的学习范围，候选需核对 |
| 本地模型生成 | 后续可选服务，使用相同教材片段和验证规则 | 首批不捆绑权重、不宣称任意教材已能离线 AI 出题 |

原题标“教材原题”；规则变式标“系统配套练习”；AI 题标“根据本教材生成，非教材原题”。相关性与答案准确性分别处理：能对应教材片段不代表答案天然正确。

## 4. 出题依据与范围控制

补题任务绑定当前用户／学习空间、教材、源文件版本、所选章节与具体片段集合。教材发生替换、解析产物发生版本变化或范围被删除时，不能让旧任务把结果写到另一本书或新来源。

先定位所选范围的实际正文，再归纳可考查要点与已有题覆盖；优先补充缺少练习的要点，避免同一例题仅换措辞重复凑题。正式知识点可暂为空，但每题必须保留正文依据和所属章／范围。涉及跨章前置内容时，只在用户所选范围内使用；需要扩大范围时明确征求选择，不能静默超纲。

发送到模型的上下文仅为本次范围内必要片段，不上传整本 PDF／Office 文件。整书任务以章节或有限内容单元分批；覆盖全书需遍历实际章节，不能沿用当前仅取前 1000 片段的截断方式。相关内容不足时减少实际候选数量并说明缺口，不让模型补写未读取的知识。

来源定位由服务端提供并校验，PDF 对应物理页，PPTX 对应幻灯片，DOCX/TXT/MD 对应阅读块；网页版只能使用其当时已实现的格式，不能因共用方案就宣称已支持所有文件。引用不是让模型自由生成的页码。每题可点击“查看教材依据”，打开实际来源；更换文件后旧引用不静默指到新内容。

文档中的指令当作教材内容，不允许通过提示注入执行工具或读取其他资料。扫描件、未知字符或无法可靠提取的公式只显示待核对和原文入口；没有可用文字证据或经核对的转录时，不声称已理解图像并生成准确题。

## 5. 题型、质量与确认保存

两端共用单选、多选、判断、填空、简答五题型。按正文适合考查的内容生成，不为凑齐题型而强造不合适的题。保存题干、选项、结构化答案、解析、期望难度、相关正文依据和可选知识点。

单选答案指向一个有效选项；多选使用选项键数组；判断使用布尔值且 false 不等于未答；填空明确标准答案／可接受答案；简答保存参考要点，仍为自行核对，不能冒充自动评分。来源与确认状态分开，兼容现有 draft／pending／approved／rejected；界面使用“待确认／可练习／暂不使用”等简单提示。

API 结果和辅助提取的原题先进入候选预览，校验题型、答案结构、来源归属、空内容、重复题和公式可读性；适用的规则计算可确定性核验。用户能查看依据、修改或放弃，确认后加入该教材题库。确认表示选择使用，不表示权威答案认证；不能将模型自报信心显示成正确率。经验证的既有模板保留其限定范围内的可练策略，不把全部旧草稿批量放行。

记录生成方式、模型名称、生成时间、提示／模板版本、来源与产物版本，不记录密钥。先预览本次实际题数；未确认候选不进入正式组卷。开始作答时固定题目版本／快照，之后编辑、删除或重新生成题目不能改写已产生的答案与成绩；旧记录无法还原过去版本时保留并说明限制，不伪造历史。

## 6. 两端配置、离线边界与费用

| 场景 | 已保存的教材配套题 | 新题生成边界 |
| --- | --- | --- |
| Windows 应用版 | 本地保存；断网可组卷、作答、查看已保存解析和重做错题 | 断网可用已支持且与正文匹配的规则；云端生成不可用，本地模型后续可选 |
| 本机运行的网页版 | 浏览器连到本机服务，断外网仍能使用本机保存的题 | 与本机服务实际配置一致，关闭服务不等于浏览器仍可离线使用 |
| 远程部署的网页版 | 保存到当前账号的教材题库，不必每次再请求 AI | 浏览器仍须连接服务器；本稿不增加 PWA 或离线网页缓存 |

如果没有可复用题、适用规则或本地模型，不能为任意教材离线生成可靠新题；应明确提示“当前无法补充，已有练习仍可使用”，不能用随机通用题掩盖缺口。

问答和教材补题可共用连接配置，但用途各自启用。网页版保护每个账户的配置，不能共享个人密钥或让某人承担其他账户费用；应用版使用 Windows 系统保护。前端只获掩码与是否已配置，密钥不进入教材内容、题目、日志或默认备份。远程 Web 的自定义接口须校验协议、目标地址和重定向，不能借配置访问内部服务；本机模型仅在明确允许的自托管边界内连接。

生成前说明本次教材范围、片段、题型与题量将发送到哪个接口及可能费用，不发送账户、全部答卷或整本文件。接口失败区分密钥错误、限流、额度不足、断网、超时、响应不合法和取消；不自动付费重试，不阻断已有学习功能。

## 7. 任务、保存与数据保护

任务具有稳定请求标识、范围、进度和结果数量。重复点击或重试不重复入库；取消后不继续自动投递付费批次，已发送内容无法撤回需如实说明。整书任务可部分完成，用户看到已完成章节、候选和失败原因，不把一章成功显示成整本完成。

任务产出先暂存候选，不覆盖已确认题、手动题或旧答案。用户确认保存采用事务和幂等约束，失败不误报成功。已有题与补充题按教材及来源版本去重，明显重复可跳过，不擅自删除旧题。模型结果中的用户、教材或知识点 ID 不作为授权依据，只接受服务端已验证的任务关联。

复用现有教材题库归属；本次不把 `Question.textbook_id` 改为可空，也不引入无教材题库。新增依据、任务和历史保护采用有版本的增量迁移，在副本验证旧题、考试、错题和掌握度不变。网页与应用数据分开保存，不自动合并或同步，源数据库不覆盖。

## 8. 分批纳入两端计划

| 批次 | 两端共同交付 | 依赖和停止点 |
| --- | --- | --- |
| T1 教材依据与覆盖 | 教材／章节实际内容定位、可考要点与已有题统计、来源与任务版本契约 | 不调用付费模型；正文不可用时可解释，保留现有教材归属 |
| T2 配套题生成与确认 | 共用接口配置、正文驱动规则／API 生成、五题型候选、查看依据、修改确认、可靠保存及历史保护 | 生成范围不越章，不根据书名凭空出题；未确认候选不能练习 |
| T3 整书补题与验收 | 按章批量任务、有限原题辅助整理、去重、中断与失败、已保存题复用及两端差异验证 | 依赖实际支持的格式；本地模型为后续独立扩展 |

网页版原 A—E 学习流程和应用版 D1—D4 应用化计划保留，本功能作为 T1—T3 共同子项目交付。具体先后由后续实施计划确定；T2 不早于 T1、身份／密钥边界和历史保护完成。添加到方案不代表已批准所有批次执行，也不把桌面 D1 扩大为一次完成全部 AI 功能。

## 9. 必须通过的验收

- TV1：导入一本只有正文、没有习题的资料，仍能针对指定章节内容生成配套候选；每题能查看实际教材依据，而非仅复制原书习题。
- TV2：同名章节内容不同的两份资料，其任务使用各自正文；只提供书名／章节标题但无正文时不盲目填题。
- TV3：题目考查内容在所选教材范围内；未介绍的概念、无关题、虚构页码和其他用户资料不能用于凑题，来源不可验证时不能标为可靠依据。
- TV4：五题型结构与 false／未答处理正确；候选可修改和确认，简答不冒充自动评分；原题与生成题标签明确。
- TV5：整书按章处理，包括超过 1000 片段的尾部章节；部分完成、取消、中断、重复点击与重试不会重复保存或谎报整书完成。
- TV6：API 的 401、429、额度不足、断网、超时和畸形／部分响应有清晰结果，不自动付费重试，不损坏已有题库或学习记录。
- TV7：已保存的配套题在桌面断网时可练且无 AI 请求；没有可用规则／本地模型时不承诺任意资料离线生成，远程网页不冒充离线应用。
- TV8：换教材、换文件版本、删章节和迟到响应不会串书或改变历史题目快照与成绩；旧数据副本升级与重复升级可验证，实际源库不覆盖。
- TV9：请求外发仅含当前任务必要片段及条件，密钥不进前端、日志或默认备份，网页版账号／桌面学习空间边界有效。

本轮仅更新方案与文档引用，不调用模型、不生成题目、不更改业务代码。用户审阅本稿后，再为对应批次制定实施计划。
