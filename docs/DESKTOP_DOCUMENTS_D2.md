## 本批范围

- PDF、DOCX、PPTX、TXT、MD 托管原件，Word/PPT 无需安装 Office 即可结构化阅读。
- 目录、正文查找、来源定位与本地阅读位置；1000 个片段之后仍可检索。
- 文件替换成功后才发布新正文；导入失败保留旧内容，文字编码错误可用原件重试。
- 旧版本引用固定到原来源，旧 PDF 引用可查看原页图像；阅读旧引用不覆盖当前进度。
- 保留现有 PDF 阅读与练习、错题、学习记录。首次扫描 PDF 提取失败时仍可阅读原页，明确需要 OCR 才能检索文字。

## 测试边界

本批不是整个桌面版计划的完成声明。仍未实现：AI API 设置、按教材正文补题、备份恢复界面、Markdown 显式关联图片导入。Markdown 图片不自动访问网络，也不会扫描任意本机路径。

复杂 Office 排版、动画、SmartArt、公式不承诺原样显示；界面提示核对原件。DOC/PPT 请另存为 DOCX/PPTX。TXT 默认严格识别 UTF-8/BOM，无法确认时提示手动选择 GB18030，不用替换字符悄悄吞掉内容。

迁移新增来源、解析版本、导入绑定、阅读位置、来源章节关联五张表，以及当前解析版本字段；旧数据不清空。升级前的 PDF 在读取或替换时登记原来源，无法核验的旧文字不冒充新文件内容。原件采用独立文件名。安装目录不保存教材和数据库；原 `test.1` 产物保留。

## 本批实施取舍

1. 复用用户指定的独立应用版仓库，未再建工作树；若需额外隔离，代价是迁移当前改动，网页版不受影响。
2. 来源发布与定位契约一起实现，代价是提交粒度更大，减少中间版本引用不一致。
3. PDF 也绑定不可变来源并保留引用原页，代价是额外兼容测试。
4. Markdown 关联图片明确列为未完成项，先保持阻止外部/越界访问；代价是这一测试增量还不能完成全部 V5 验收。
5. 可选 AI、教材补题和备份恢复按后续批次实现；本包先验证其依赖的资料来源，代价是不能据此验收完整桌面版。
6. Office 采用结构化阅读并提示核对复杂对象，不承诺完整动画、SmartArt、公式与页面排版；需要原样阅读时仍需原文件或 PDF。
7. 干净 Windows、离线 WebView2 分发及真实用户数据库迁移不列为本次已通过项目；仅使用临时数据库和合成文档验证，尚需单独兼容验收。

## 延后的小问题

- 首次打开较短的结构化资料，未点击目录或翻页时不会生成继续阅读记录；本批测试建议点击一次章节。
- 中断导入后的部分旧提示仍写“重新上传”，实际可使用原件重试入口。
- 沿用 D1 的安装器检测限制：机器级 WebView2 残留空版本可能遮蔽用户级有效版本，尚待兼容批次处理。
